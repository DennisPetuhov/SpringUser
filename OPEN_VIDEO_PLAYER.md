# 🎥 Video Player Access

## ✅ Correct URL (Spring Boot Server):
```
http://localhost:8080/video-test.html
```

## ❌ Don't Use (IntelliJ Static Server):
```
http://localhost:63342/...
```

## 🚀 Quick Start:
1. Make sure Spring Boot is running (`./gradlew bootRun`)
2. Copy and paste the correct URL above into your browser
3. Enjoy synchronized video streaming!

## 🔧 Features Available:
- ✅ Video streaming with byte-range support
- ✅ Real-time synchronization across multiple clients
- ✅ Live chat during playback
- ✅ Viewer counter
- ✅ WebSocket connectivity

## 🎯 Test Multi-User Sync:
1. Open multiple browser tabs with the correct URL
2. Use different User IDs (user1, user2, etc.)
3. Join the same video session
4. Test synchronized play/pause/seek
